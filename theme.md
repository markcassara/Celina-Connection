# Celina Connection Brand Theme

## Colors

- Background cream: `#f7f1e4`
- Surface: `#ffffff`
- Surface tint: `#f7ead4`
- Primary navy: `#173542`
- Muted text: `#66716d`
- Teal accent: `#1f6473`
- Gold/coral accent: `#d28f33`
- Sun highlight: `#f2c35d`
- Mint tint: `#e4eee9`

## Typography

- Body: Manrope
- Display: Fraunces

## Assets

- Logo: `/assets/brand/cc-logo.png`
- Default social image: `/assets/social/business-owners-banner.jpg`
- Background texture: `/assets/backgrounds/map-paper.jpg`

## Usage Notes

- Use navy in place of black for primary text and dark controls.
- Use the light cream background as the default page backdrop.
- Use the CC logo image instead of the old orange generic icon.
- Use the business-owner banner for default Open Graph and Twitter previews.
